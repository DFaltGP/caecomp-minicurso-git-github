# Calculadora de Frete · CAECOMP UEMG

Projeto base para o **Minicurso de Git e GitHub para Versionamento** (Semana de Pesquisa e Extensão 2026 - UEMG).

## Como executar localmente ou no GitHub Codespaces

Inicie um servidor HTTP simples na raiz do projeto:

```bash
python3 -m http.server 3000
```

Abra `http://localhost:3000` (ou a URL encaminhada pelo Codespaces) no navegador.
